# DNS Troubleshooting Evidence

## Resolver configuration
Command:
cat /etc/resolv.conf

Observation:
- Configuration generated by NetworkManager.
- A VMware virtual gateway address is configured as the DNS server.

## System resolver
Command:
getent ahosts archlinux.org

Result:
- IPv4 and IPv6 address records returned successfully.

## DNS over UDP through configured resolver
Command:
dig archlinux.org A +noall +answer +stats

Result:
- A record returned successfully.
- Query time: 231 ms.
- Transport: UDP.

## DNS over TCP through configured resolver
Command:
dig +tcp @<configured-resolver> archlinux.org A +noall +answer +stats

Result:
- Connection refused on TCP port 53.
- No DNS answer returned.

## Direct DNS queries to Cloudflare
Commands:
dig @1.1.1.1 archlinux.org A +time=3 +tries=1 +noall +answer +stats
dig +tcp @1.1.1.1 archlinux.org A +time=3 +tries=1 +noall +answer +stats

Results:
- UDP query successful; query time: 99 ms.
- TCP query successful; query time: 71 ms.
- Both returned the expected A record.

Conclusion:
DNS over UDP and TCP works when querying Cloudflare directly.
The configured virtual gateway resolver responds over UDP but
refuses TCP connections on port 53.
The underlying reason for this difference was not established.
